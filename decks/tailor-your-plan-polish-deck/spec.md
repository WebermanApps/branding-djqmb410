## Cards

### 1. Tint Treatment

How should each category's tint show?

- **A. Full Tile Wash**: The whole category card is filled with its light tint. Shown on Roof And Outside in Warm Sand #F8F1EA, with Inside The Home peeking in Soft Cream #FCF9F4.
- **B. Tinted Header And Edge**: The header and a light edge use the tint, and the list stays on white. Same categories and hex values as A.

The per-category tints are the live Home FAQ card hexes: Heating And Cooling #F7EBE5, Water And Plumbing #EEF4F8, Roof And Outside #F8F1EA, Inside The Home #FCF9F4, and Seasonal Equipment #F3E6DF. This pair is only how the tint shows, not whether to use a tint. No green as a main look. The Water And Plumbing tint is a light lagoon wash from the live FAQ set, not green.

### 2. Row Mark

Should each service row have a small mark?

- **A. Name Only**: The live list: the name, the add-on tag, and the price, with no mark on the row. The section icon stays in the header.
- **B. A Pip On Each Row**: A small pip sits in the left padding of each row. Heating And Cooling uses terracotta; Water And Plumbing, peeking in, uses lagoon. Names and prices stay as they are.

A full line icon beside the name did not fit the six-row cards on a phone, so this is a small pip that keeps every name on one line. Shown on Heating And Cooling. Tinted header and edge is the baseline.

### 3. Price Color

How should the right-aligned price feel?

- **A. Ink Price**: The live right-aligned Khand price in ink #1A1A1A, with Quote in terracotta #A8431F.
- **B. Terracotta Price**: The same right-aligned Khand price, in terracotta #A8431F, including the dollar amounts and Quote.

This keeps the Right-Aligned Price pick from this morning; it only changes the color, not a return to price pills. Shown on Water And Plumbing, with live prices such as +$19/mo, $149, $650, and $95. #A8431F meets 4.5:1 on every category tint.

### 4. Open Row

How should a row look when it opens to show more?

- **A. Plain Inline**: The official catalog name and the short description drop in under the row, in the same field as the list.
- **B. Inset Detail Panel**: The same official name and description sit in a slightly inset cream panel with a light edge, still inside the card.

Shown on Seasonal Equipment, with Generator Service opened. The official catalog line is Generator Annual Service, and the description is the live catalog line, word for word. The collapsed list is unchanged, so the section still fits one phone screen.

### 5. Add-On Tag

How should the Plan Add-On and One-Time Add-On tags look?

- **A. Plain Text Tag**: The live tag under each name, in a slightly darker brown #5C534C so the type meets 4.5:1.
- **B. Soft Tint Tag**: The same wording, in a small soft-tint chip under the name. Plan Add-On and One-Time Add-On stay the labels.

This keeps the Tag On Each Row pick; it only changes how the tag is drawn. Shown on Inside The Home, with live prices such as Radon Test $100 and Bath Fan Clean And Check $95. The live tag gray #8A8178 is under 4.5:1, so both options use #5C534C.
